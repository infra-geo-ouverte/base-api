# @igo2/base-api

Librairie d'utilitaires de base pour les projets API IGO.

## 🚀 Fonctionnalités

- **Base64** : Encodage et décodage.
- **Object Utils** : Helpers pour la manipulation d'objets (clone, merge).
- **String Utils** : Fonctions communes de manipulation de chaînes.
- **UUID** : Génération d'identifiants uniques.
- **Sanitizer** : Protection XSS et assainissement des données.
- **Template** : Moteur de templating basé sur Handlebars.

## 💾 Installation

```bash
npm install @igo2/base-api
```
