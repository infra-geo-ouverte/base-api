# @igo2/fastify

Base API pour Fastify, fournissant un ensemble de plugins réutilisables et de patrons pour construire des APIs robustes avec Fastify.

## 🚀 Fonctionnalités

- **Authentification** : Support pour OIDC et providers personnalisés.
- **Database** : Intégration avec Drizzle ORM et Sequelize.
- **Logger** : Journalisation standardisée avec Pino.
- **Monitoring** : Intégration Sentry.
- **Swagger** : Génération de documentation OpenAPI.
- **Configuration** : Gestion de la configuration basée sur l'environnement.

## 💾 Installation

```bash
npm install @igo2/fastify
```
